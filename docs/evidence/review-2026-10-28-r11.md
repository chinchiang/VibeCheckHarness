# 設計審查紀錄：第十一輪（2026-10-28 r11）

> **這份紀錄的用途**：保存第十一輪審查的發現與處理方式，讓 `rule_version 05-v0.9` → `05-v0.10`、run 生命週期與 W／B 階段產物納入錨定模型、Lite 的證據價值都能追溯到審查發現；也列出改變做法與留到之後的項目。
>
> - **審查對象**：main 的 `2823823`（第十輪 PR #28～#31 與 BL-66／01／47／05、`suspend` 變體的 PR #32、#33 合併之後）。
> - **方式**：三個彼此獨立的唯讀審查，分別看 validator 與 schema 能否被繞過、裁決／統計／校準邏輯、方法論與文件。每項繞過都附在記憶體中重現的 probe；最嚴重的 6 項（未簽署的 resume、inventory 未釘住、校準政策常數、同家族回溯作廢反駁票、終態不由 `gaps` 推導、關卡輪數）由主審查者重跑確認。
> - **機械性檢查在審查時全部通過**：validator 主範例 4,573 項、三個變體零錯誤、1,503 個測試、0 個壞連結、四個 generator 最新、22 份突變清單錨點 0 個過期、錯誤碼 314 個全部有測試；決定表與程式在 3,932,160 組輸入上零不符。
> - **處理原則**：依 [CONTRIBUTING.md](../../CONTRIBUTING.md)，每個宣稱「修好」的錯誤都有回歸測試：測試在修正前的 commit 上失敗、修正後通過，並且逐一停用每個新檢查確認對應的測試失敗（`tests/mutations/r11_*.json`，以 `tools/mutation_check.py` 重跑）。
> - **結果**：四個 PR 全部合併；三個設計決定由使用者裁定（§7）；留到之後的項目見 §8。

## 1. 總評

- **穩的部分**：錨定鏈（關卡紀錄、裁決、報告 manifest 的內容 hash；終態後不能再加行；跨 run 的 `anchor_counter`）；B 階段 job／事件／結果三方對帳；關卡核准者來源與職責分離；嚴格載入器；決定表與程式窮舉零不符；加證據不會讓狀態變弱；θ 守衛、同根取最強票、黑箱叢集不能用票確認；三個變體走過的路徑與文件一致。
- **不足分三類**：
  1. **run 生命週期與 W 階段產物在錨定模型之外**：`SUSPENDED`／`STOPPED` 不需要簽署的 `run_resume` 就能回到 `RUNNING`（不需要金鑰）；W0 inventory、DFD、Commander 計畫沒有任何錨定事件釘住，完成的 run 仍可改寫；終態不由 `gaps` 推導；關卡輪數上限只是文字。
  2. **裁決規則的參數與獨立性計算**：校準檔的政策常數與 θ 的切分統計全部來自檔案，validator 只檢查自我一致，改數字就能把叢集推成 CONFIRMED；同家族成員事後加入叢集會回溯作廢已投的計權反駁票，讓 DISPUTED 變成不進 G2 的 LIKELY（受測碼的注入文字就能做到，不需要金鑰）。
  3. **方法與文件的缺口**：回歸 run 的「已修正」在裁決狀態機裡沒有可表達的狀態；Lite 一人持有全部金鑰與主機，稽核鏈對第三方沒有證明力但文件沒說；Lite 無法抑制誤報；人力估算四處互相矛盾；版本字串、SKIPPED／MANUAL、純白箱終態、帶簽章事件清單等數處文件矛盾；README 計數與術語表過時。

## 7. 排名調整、使用者決定與改變做法

- **使用者裁定的三件事**：反駁票的回溯作廢「兩者都做」（投票時成員＋`no_eligible_verifier` 進 G2）；回歸 run 的已修正採新裁決狀態 `FIXED`（因此與 PR2 同一次升 `rule_version`，而不是審查建議的 `baseline_state: fixed` 欄位）；Lite 允許自簽 `wont_fix`／`needs_info`。
- **G1 估算改以 70 條計**，而不是把 02 的基準改小：ASVS L1 是方法論的基準，估算跟著方法走。
- **純白箱 run 的終態取 `COMPLETED`**（03 §5.2 的版本）：終態只由 `gaps` 推導，沒有黑箱階段不是缺口。
- **`rule_trace` 的 `θ_confirm=` 第一版寫成可選前綴**，正確值的測試仍通過（因為根本沒比對）；改為把 `θ_confirm`／`θ_reject` 列為名稱並正規化，並把「寫錯的值在每種寫法下都報錯」加進測試。
- **突變工具一次誤報 MISSED**：同一份清單的前一個突變用了過時的錨點，`continue` 之後沒有還原；該突變單獨重跑與整份清單重跑都是 CAUGHT。
